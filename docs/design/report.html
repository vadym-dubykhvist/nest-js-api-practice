Design Research — Events platform

Event-first web app · Next.js + Tailwind v4 + shadcn · 2026-06-04

TL;DR. Топ event-продукти (Luma, Partiful, Eventbrite) роблять обкладинку івента героєм, а хром тримають нейтральним і тихим. Беремо цю модель: чистий нейтральний UI + один акцентний колір для Register; колір на екран приносять самі івенти. Реєстрацію — у липку панель (desktop збоку / mobile знизу) з тогглом «гість ↔ увійти».

Палітра (core)

Light-значення. Повний набір light/dark + CSS-змінні та @theme для Tailwind v4 — у design-framework.md.

Типографіка: Geist Sans (UI) + Geist Mono (дата/час/лічильники, tabular-nums). Заголовки 600–700, tracking −0.02em; body 16/1.6.

Recommendations

  1. Event detail = обкладинка-герой + липка панель реєстрації (desktop збоку, mobile bottom-bar).
  2. Register-модалка з тогглом «Гість / Увійти» — гостю 2-3 поля, юзеру лише note.
  3. Events list = грід обкладинок + горизонтальний фільтр-бар (tag/location/пошук, badge upcoming/past/full).
  4. Capacity / status / rating — окремі компоненти-сигнали, не сірий текст.
  5. Нейтральний хром + один акцент — різнобарв'я тільки в обкладинках.
